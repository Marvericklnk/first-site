# First Web Design Site

An early HTML and CSS website with home, about and services pages. Forms are visual examples and do not send messages.

[Live demo](https://marvericklnk.github.io/first-site/)

![Project screenshot](screenshots/preview.jpg)

## Run locally

Download the code and open `first-site/index.html` in your browser. You can also open the folder in VS Code and use Live Server.
